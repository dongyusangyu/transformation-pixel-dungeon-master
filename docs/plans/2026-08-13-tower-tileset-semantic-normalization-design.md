# 高塔环境贴图语义统一规格

## 目标

统一六套高塔环境图集与原项目 `DungeonTileSheet` 槽位契约，修复门方向、固定物件变形、植被重复叠加及水岸内外反转问题。涉及中式厅堂、哥特城堡、星象秘法藏书塔、塔芯机括工坊、空中温室与炼金花园、寒霜封存库。

## 图块契约

- `18/19`：井，逐像素沿用 `tiles_sewers.png`。
- `64/120/232`：炼金釜平面、本体和顶部，逐像素沿用 `tiles_sewers.png`。
- `56-59`：平面门；`112-115`：竖向墙体中的 raised 门本体；`116`：横向墙体门槛。
- `224-226`：竖向门顶部；`227-229`：横向墙体中的关闭、上锁、晶体门顶部。
- `66/67/69/70`、`122/123/125/126`、`234/235/237/238`、`250/251/253/254`：主题低层、本体、顶部和底部植被层。
- `32-47`：水岸掩模。完全透明像素保留给动态水面，半透明像素为岸线，实心像素为主题地板。

## 渲染规则

高塔分支中，草、高草、枯草和余烬只使用当前主题图集，不再叠加 `terrain_features.png` 的深度区域植被。陷阱和实际种植的植物不受影响。

## 验收

- 六套图集尺寸和透明度契约保持为 `256x256`。
- 固定物件槽位与下水道原版完全一致。
- raised 门不得与平面门逐像素相同，横向门顶部必须表现关闭状态。
- 16 种水岸的 alpha 掩模与原版一致，透明水域中不写入草地像素。
- 高塔分支不再返回区域植被覆盖图块，普通地牢分支行为不变。
