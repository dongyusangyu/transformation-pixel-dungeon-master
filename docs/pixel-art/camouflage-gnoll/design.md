# 迷彩豺狼美术与动画设计记录

## 参考拆分

- 物种轮廓：`gnoll.png`
- 紧凑近战装备：`gnoll_guard.png`、`gnoll_sapper.png`
- 披肩层次与豺狼头部一致性：`gnoll_geomancer.png`
- 中毒行为：`FungalSentry.attackProc()`
- 草地联动：`FungalSpinner`
- 后段数值：`Eye`、`Succubus`、`Scorpio`

概念图由内置生图功能生成，四张豺狼精灵表均作为图像参考。提示词要求同一角色展示待机、行走、攻击蓄力、淬毒命中、草地伪装和连续死亡动作，并明确要求最终可压缩到 12×16。

## 造型语言

- 长吻、尖耳和尾巴负责维持豺狼轮廓。
- 叶片斗篷集中在背部和肩部，不遮住头部与持刀手。
- 毛色使用棕褐色；斗篷使用三阶苔绿色。
- 淬毒只使用一个紫色强调色，避免被误读成持续发光。
- 短刃沿角色右侧运动，攻击蓄力和命中帧保持同一只手。

## 调色板

可见颜色共 11 个：外轮廓、深棕、棕、褐、浅褐、深苔绿、苔绿、浅苔绿、毒紫、刀刃灰、眼睛黄。透明像素使用 `(0,0,0,0)`。

## 帧表

| 帧 | 动作 |
|---:|---|
| 0–1 | 呼吸、耳尾轻动 |
| 2 | 短刃上举，后脚支撑 |
| 3 | 身体前压，短刃水平命中 |
| 4–7 | 四相跑动，腿部交替、尾巴跟随 |
| 8 | 受创弯腰 |
| 9 | 跪倒并松开武器 |
| 10 | 完全倒地 |
| 11–12 | 降低重心并融入草丛的伪装循环 |

精灵表尺寸为 156×16，每帧 12×16。预览图只使用 8 倍最近邻放大。
