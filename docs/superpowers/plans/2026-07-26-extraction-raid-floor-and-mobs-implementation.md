# 搜打撤楼层与怪物实现计划

## 任务 1：建立失败测试

- 新增楼层契约测试：位置、随机种子、房间数、无虚空、无楼梯、连通性、怪物数量和构成。
- 新增怪物契约测试：继承关系、破隐概率、破时停概率、延迟伤害和铁卫初始激活。
- 运行定向测试并确认测试因目标类尚不存在而失败。

## 任务 2：实现专属怪物

- 在搜打撤目录下新增四个怪物子类。
- 为时间气泡与沙漏时停暴露只读剩余时长。
- 在玩家时停消耗行动的位置调用窃时魅魔判定。
- 运行怪物定向测试。

## 任务 3：实现随机楼层

- 为 `Level.create()` 增加可覆写的楼层随机种子入口。
- 新增搜打撤专用房间、无虚空大厅绘制器和 `ExtractionRaidLevel`。
- 将第 31 层分支 1 路由到新楼层，并禁止跨层传送。
- 运行楼层定向测试。

## 任务 4：文本与验证

- 补充四个怪物的中英文名称和说明。
- 运行全部新增测试。
- 运行 `:core:compileJava`，确认主代码可编译。
- 审查差异，确保没有混入本批范围外的奖励和商店功能。
