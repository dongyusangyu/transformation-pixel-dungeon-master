# 地表店主实现计划

> 已由用户确认设计。实现采用测试驱动方式，每一阶段先添加会失败的测试，再写最小实现并运行回归测试。

## 1. 可测试的定价与查询核心

- 修改 `Shopkeeper`，增加接受显式楼层的售价重载，保留原接口行为。
- 修改 `Heap`，增加可选售价层、价格计算和 Bundle 持久化。
- 修改 `WndTradeItem` 与货堆标题，使购买全过程读取货堆价格。
- 新增 `SurfaceShopkeeper` 的查询解析、目录匹配、限购计数和 Bundle 持久化。
- 测试第 20/25 层定价、尾随 `xN`、白名单/黑名单、五件限额与存档恢复。

## 2. 店主窗口与交易

- 复用普通店主的出售和回购行为。
- 添加查询文本框、错误提示与购买确认窗口。
- 成交时原子检查限额和金币，扣款后交付物品并更新计数。
- 测试失败路径不会扣款或改变计数。

## 3. 第 0 层商店房间

- 扩建东北房屋并定义房间边界、门、店主位置。
- 在 `SurfaceTownLevel.createMobs()` 中分别确保东隅桑榆与店主各一个。
- 沿房间内缘生成标准高层商店风格库存，全部货堆设置售价层 20。
- 装备通过恶魔层生成组生成，保证只出现四阶或五阶装备。
- 测试两名 NPC 不在同一房间、货架位置和定价元数据正确。

## 4. 本地化与验证

- 补充英文和简体中文名称、描述、菜单、输入、确认及错误文本。
- 运行新增测试、相关模块测试和完整 `core:test`。
- 运行差异检查，确认未覆盖工作区内无关的既有修改。
