# 瘟疫骑士药瓶选点与净化器战术设计

## 目标

让瘟疫骑士围绕净化触发器作战，并把净化器改为独立于 Boss 行动的十回合机关；同时允许玩家通过主动清除开场苍白瘴气召出 Boss，但只有踩净化器会执行全图清场。

## 药瓶选点

- 孵化阶段药瓶冷却结束时，先计算原有玩家预测格。
- 若从 Boss 到预测格满足 `Ballistica.PROJECTILE`，向预测格投掷。
- 否则检查当前净化触发器；若其本格满足同一弹道规则，药瓶落在触发器本格，实际九宫格播种继续排除触发器本格，因此形成环绕封锁。
- 两者都不可投射时，从 Boss 竞技场的有效播种格中随机选点。
- 选择结果同时作为投掷动画落点和九宫格播种中心，避免动画与效果错位。

## 守点移动

- Boss 处于游荡状态时，将净化器周围最近的可通行、未占用格作为首选移动目标。
- Boss 因距离控制或恐惧进入逃离逻辑时，同样先向该守点格移动；已经抵达守点格时允许原地等待，不强制离开净化器。
- 无有效守点格或路径受阻时，回退到原有移动逻辑。

## 净化器冷却与外观

- 激活后净化器照常转移，进入 10 个英雄回合冷却。
- 冷却只在英雄回合开始时推进，不再由瘟疫骑士行动、攻击动画或阶段转换推进或重置。
- 冷却时 `PlagueBrazier.active=false`，显示为未填充陷阱；归零时恢复 `active=true` 和正常白色陷阱外观。
- 冷却数值及外观在存档恢复后重新同步。

## 双开场路径

- 路径一：英雄踩下可用净化器，清除全图三类瘴气并生成 Boss；首次触发不造成 Boss 伤害。
- 路径二：任何外部效果调用 `PaleMiasma.clear` 或 `fullyClear` 并实际移除开场苍白瘴气时，立即生成 Boss。
- 路径二不额外调用全图清场；只有外部效果自身覆盖的格子被清除，其余开场末日行列瘴气保留。
- 苍白瘴气自然演化不触发路径二；净化器执行全图清理时临时抑制外部清除回调，防止重入或重复生成。

## 验证

- 单元测试覆盖三级药瓶选点、守点优先级、10 英雄回合冷却、陷阱 active 外观及 Bundle 往返。
- 接线测试覆盖 `Ballistica.PROJECTILE`、苍白瘴气清除通知与净化器清场抑制。
- 回归覆盖瘟疫骑士、瘴气、净化器控制器、Boss 楼层与素材测试。
