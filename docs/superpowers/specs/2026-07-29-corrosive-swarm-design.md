# 腐蚀蝇群设计规格

## 目标

新增高塔普通怪物“腐蚀蝇群”（`CorrosiveSwarm`）。它继承普通蝇群的飞行、近战状态机和受击分裂行为，但采用高塔后段数值，并在受到任意正数伤害时爆裂，对周围八格生物施加可叠加持续时间的腐蚀；爆炸还会以 0 伤害触发相邻同类，形成有限连锁。

## 数值

| 属性 | 数值 |
|---|---:|
| HP / HT | 200 |
| 伤害 | 15–25，均值 20 |
| 命中 | 40 |
| 闪避 | 20 |
| 护甲 | 0–10，均值 5 |
| 移速 | 1，保留默认实现 |
| 攻击间隔 | 1，保留默认实现 |
| 经验 | 13 |
| 经验上限 | 26 |
| 额外掉落 | 无 |

分裂体仍是 `CorrosiveSwarm`，继承普通蝇群的剩余生命分摊、分裂延迟、四方向空位检查、状态继承和分裂体经验为 0 的规则。腐蚀蝇群仅在受击前 HP 严格大于 10 时允许分裂；HP 等于或低于 10 时不再分裂。

## 腐蚀爆裂

- `damage(int damage, Object source)` 收到任意正数伤害时触发一次新的爆裂链，包括直接攻击、Buff、陷阱和环境伤害。
- 爆裂中心为腐蚀蝇群当前位置，目标为 `PathFinder.NEIGHBOURS8` 中的所有角色。
- 不影响爆裂者自身。其他 `CorrosiveSwarm` 会先受到同样的腐蚀，再收到 0 点连锁伤害并爆裂。
- 每条爆裂链维护已触发集合，同一只腐蚀蝇群在同一条链中最多爆裂一次，避免相邻同类无限互相触发；普通的外部 0 伤害不会新建爆裂链。
- 目标没有 `Corrosion` 时调用 `set(2f, 1, CorrosiveSwarm.class)`，即初始每回合 1 点、持续 2 回合。
- 目标已有 `Corrosion` 时调用 `extend(2f)`，每次爆裂追加 2 回合；伤害强度仍由现有 `Corrosion` 自身的回合递增机制处理。
- 爆裂先播放两帧专属动画和黑紫/腐蚀色粒子，再进入父类受伤流程。

## 生成规则

两种高塔怪物均不得进入正常主线 1–25 层的怪物池。它们只在 `TowerLevel.createMob()` 中生成。

高塔内部使用正整数楼层，但界面显示为负数：

| 单次随机数 | 高塔显示楼层 -1 及以下 |
|---|---|
| `[0.0, 0.2)` | 迷彩豺狼 |
| `[0.2, 0.4)` | 腐蚀蝇群 |
| `[0.4, 1.0)` | 原有怪物池 |

所有高塔楼层均使用此分配，不再限制迷彩豺狼从第 6 层开始出现。

## 相似怪物

- 分裂、飞行和基础动画：`Swarm`、`SwarmSprite`。
- 腐蚀 Buff：`Corrosion`、`CorrosiveGas`。
- 爆裂范围与黑色飞溅表现：`ChampionEnemy.Corrosion`。
- 高塔数值：`Eye`、`Succubus`、`Scorpio` 和高塔怪物流程基准。

普通 `Swarm.split()` 当前固定构造 `new Swarm()`。为保留子类类型，在 `Swarm` 中新增 `protected Swarm createSplit()` 工厂钩子，并新增 `protected boolean canSplit(int damage)` 阈值钩子；`split()` 的其余状态复制逻辑保持原样。普通蝇群维持原阈值，腐蚀蝇群覆盖为“原有剩余生命条件成立且受击前 HP > 10”。

## 美术与动画

- 参考 `swarm.png` 的 16×16 扁平横向群体轮廓。
- 红白腹囊改成黑紫能量核心、灰黑翅膀和橙绿色腐蚀囊。
- 每帧最大 16×16，透明 RGBA，硬边、无抗锯齿，8–12 个可见颜色。
- 精灵表共 17 帧、272×16：
  - 0–5：待机与飞行循环。
  - 6–9：攻击。
  - 10–14：死亡。
  - 15–16：受击膨胀、环形爆裂。
- 概念图展示待机、飞行、攻击、分裂、爆裂和死亡，最终像素素材重新逐帧绘制，不直接缩小概念图。

## 文案

名称：腐蚀蝇群

描述：这种蝇群的体内充满了躁动的黑暗能量，仿佛轻轻一碰就会爆炸。每次受到伤害，它们都会爆裂并四散分裂，把可不断积累的腐蚀淤泥泼洒到周围生物身上。

## 验收

- 数值、默认速度与攻击间隔测试通过。
- 普通蝇群分裂体仍为普通蝇群，腐蚀蝇群分裂体保持腐蚀蝇群类型。
- 首次腐蚀为 1 点、2 回合；重复爆裂追加 2 回合。
- 普通 0 伤害不爆裂；正伤害开启新爆裂链，同类以 0 伤害继续连锁，同一条链中每只最多爆裂一次。
- 腐蚀蝇群受击前 HP > 10 时可分裂，HP <= 10 时不可分裂；普通蝇群分裂阈值不变。
- 正常主线生成池不包含两种高塔怪物；高塔从显示 -1 层起执行 20/20/60 分配。
- 精灵表 17 帧全部非空，单帧 16×16，硬透明边缘，可见颜色不超过 12。
