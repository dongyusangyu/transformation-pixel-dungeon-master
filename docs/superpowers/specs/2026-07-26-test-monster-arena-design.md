# 怪物测试场设计

## 目标

在测试模式中提供一个固定按第 30 层环境运行的独立怪物测试场，用于放置怪物、修改阵营并观察战斗表现。

## 楼层

- 使用 `depth = 30`、`branch = 2`，与主线和铁匠支线存档隔离。
- 地图尺寸为 63×63，中心坐标为 `(31, 31)`。
- 到中心距离不超过 30 格的区域为圆形空地，其余区域为墙。
- 不生成怪物、物品、陷阱、楼梯、楼层转换或自然刷新器。
- 玩家进入时出现在圆心。

## 出入

- 阵营调试器新增一个动态动作：普通楼层显示“进入怪物测试场”，测试场内显示“离开怪物测试场”。
- 进入前由英雄 Buff 保存原深度、分支和位置，数据随存档持久化。
- 进入和离开均使用 `InterlevelScene.Mode.RETURN`，避免依赖楼梯或 `LevelTransition`。
- 离开时返回进入前的位置；返回信息缺失时拒绝离开并显示提示。

## 验证

- 测试圆形边界、中心位置、尺寸和测试场身份判断。
- 测试楼层生成后没有楼梯转换、怪物和物品。
- 编译核心模块并运行聚焦测试。
