# 迟创魔蝎六连击设计

## 目标

将搜打撤楼层的迟创魔蝎改为常规伤害怪物：每次攻击行动只进行一次攻击，每次基础伤害为 2–8，攻击间隔为原来的六分之一。

## 行为

- 删除延迟伤害语义；不附加 `Viscosity.DeferedDamage`。
- 敌人在攻击范围内时，迟创魔蝎每个攻击行动只调用一次原生攻击流程。
- 每一击独立进行命中、伤害、护甲减伤和原版魔蝎的致残判定。
- 每次攻击后仅消耗原版攻击延迟的六分之一，因此在一段正常攻击间隔内可攻击六次。

## 验证

回归测试断言攻击间隔为原版魔蝎的六分之一，并对大量伤害掷骰结果断言其闭区间为 2–8。编译生产代码与运行搜打撤怪物测试。
