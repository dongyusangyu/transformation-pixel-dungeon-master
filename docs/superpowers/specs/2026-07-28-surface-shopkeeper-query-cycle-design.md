# 地表店主查询商品与限购周期扩展设计

## 目标

扩展第 0 层地表店主的“查询购买”：

- 允许查询购买 `ScrollOfExtraction`。
- 允许查询购买小包口粮 `SmallRation`，但不开放其他食物。
- `ScrollOfExtraction` 的基础价值改为每张 40 金币；最终查询售价继续沿用第 25 层商店定价公式，不固定为 1000 金币。
- 两种新增商品继续受“每个具体物品最多查询购买 5 个”的限制。
- 玩家每正式结算 5 次搜打撤小游戏后，店主的全部查询购买计数清空，并从新周期重新累计。

## 结算与周期

只有通过地表店主进入的搜打撤小游戏参与限购周期计数。东隅桑榆提供的十步模式和无尽模式完全不参与。

搜打撤满足以下任一结果时计为一次：

- 玩家取得钥匙并成功撤离。
- 玩家在搜打撤楼层死亡并触发失败返回。

玩家主动放弃搜打撤时不计次数。一次已经结束并移除 `RaidSession` 的搜打撤不能重复计数。

`TreasureHuntRecords` 保存累计有效搜打撤结算次数，并将 `累计次数 / 5` 作为当前限购周期编号。店主对象保存自己最后同步的周期编号。当前周期与店主周期不同时，店主清空全部按物品分类的查询购买计数，并更新周期编号。

搜打撤结算后会尝试通知当前楼层的地表店主同步；返回地表并恢复店主对象时还会再次同步，玩家与店主交互、检查额度或记录购买时也会同步，作为跨楼层与存档恢复的安全保障。

## 查询目录与价格

`ScrollOfExtraction` 和 `SmallRation` 显式加入查询目录。`SmallRation` 是食物类型的唯一例外，不因此开放 `Food` 的其他子类。

价格继续调用店主已有的第 25 层定价：

- `ScrollOfExtraction` 基础价值为 40。
- `SmallRation` 保持基础价值 10。
- 查询购买最终单价由现有深度公式计算。

## 存档兼容

累计有效搜打撤结算次数随 `TreasureHuntRecords` 持久化。店主的周期编号随店主对象持久化。

旧存档缺少搜打撤结算次数时按 0 处理；旧店主存档缺少周期编号时，以恢复时的当前周期作为基准，保留已有购买计数，不产生意外清空。此前错误记录的十步/无尽结算次数使用不同的存档键，不迁移到正确的搜打撤计数中。
