# 瘟疫骑士二、三阶段瘴气投掷动画设计

## 目标

所有由瘟疫骑士技能主动播种的二、三阶段 Blob 都应有可见的药瓶投掷动画，且颜色、落点和实际瘴气类型一致。

## 设计

- 二阶段“检疫封锁”在预警时向播种条带的代表格投掷翡翠药瓶，命中产生 `0x63D13F` 绿色飞溅。
- 三阶段“苍白冲锋”与“末日行列”投掷银白药瓶，命中产生 `0xC8C3E8` 苍白飞溅。
- 代表格从实际有效播种格中确定，优先选择数组中点；无有效格时不播放动画。
- 末日行列三次推进分别播放一次投掷动画：第一波随首次预警播放，后两波在各自预警建立时播放。
- 动画只提供反馈，不延迟或改变既有技能结算、伤害、冷却、播种量和存档状态。

## 验证

- 源码接线测试确认二阶段与三阶段均使用药瓶弹道、对应贴图与颜色。
- 逻辑测试确认每种技能映射到正确药瓶、飞溅色与代表格。
- 回归运行瘟疫骑士、Blob 和素材测试。
