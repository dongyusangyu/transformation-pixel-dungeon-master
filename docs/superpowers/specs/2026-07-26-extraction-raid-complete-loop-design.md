# 搜打撤小游戏完整闭环设计规格

## 目标

在现有第 31 层、分支 1 的 `ExtractionRaidLevel` 上完成一个可重复游玩的
搜打撤闭环。玩家只能与 0 层 `SurfaceShopkeeper` 交谈并支付 1000 金币入场；
在随机楼层内搜索藏品、投掷武器和高阶装备，取得水晶钥匙后前往指定撤离房间。
成功撤离保留本局战利品，死亡或主动放弃则失去本局战利品并承受轻度背包损失。

## 藏品价格与数学期望

沿用现有两套独立概率：

- 固定藏品稀有度：TOP 1%、RARE 4%、UNCOMMON 10%、COMMON 85%。
- 实例品质：传奇 0.1%、史诗 1%、稀有 10%、普通 88.9%。
- 每局等概率生成 3 或 4 件藏品，平均数量为 3.5 件。

基础价格如下：

| 固定稀有度 | 藏品与基础价格 |
|---|---|
| TOP | `MuiscaGoldenRaft` 5000 |
| RARE | `ImperialCrown` 4500、`PakalJadeMask` 4000、`SuttonHooHelmet` 3500 |
| UNCOMMON | `BookOfKells` 2500、`CholaNataraja` 2300、`DojigiriYasutsuna` 2100、`TurquoiseSerpent` 1900、`RuWareBowl` 1700、`IncaGoldenLlama` 1500 |
| COMMON | `LewisChessQueen` 1400、`HarbavilleTriptych` 1300、`AlMughiraPyxis` 1200、`BlacasEwer` 1100、`GreatKhanPaiza` 1000、`GoryeoMaebyeong` 900、`JavaneseGoldCup` 800、`EthiopianProcessionalCross` 600、`GreatZimbabweBird` 500、`DjenneTerracottaFigure` 500 |

品质倍率为普通 ×1、稀有 ×2、史诗 ×5、传奇 ×10。TOP 且传奇的藏品
额外获得 4,950,000 金币“镇馆溢价”。

- 最低售价：500。
- 最高售价：`5000 × 10 + 4,950,000 = 5,000,000`。
- 加权平均基础价格：1200.5。
- 加权平均品质倍率：1.149。
- TOP 传奇溢价的单件期望贡献：49.5。
- 单件期望售价：`1200.5 × 1.149 + 49.5 = 1428.8745`。
- 每局藏品期望总售价：`1428.8745 × 3.5 = 5001.06075`。

这里的 5000 指成功带出并出售本局全部生成藏品时的毛收益期望，不扣除入场费，
也不乘撤离成功率。

## 楼层战利品

每次新建楼层时独立生成并分散到不同可通行格：

- 3–4 件 `TreasureGenerator.random()` 藏品。
- 1–2 组投掷武器，每组数量固定为 3。
- 投掷武器的等阶使用装甲石像所在最终章节的同一套概率：四阶 20%、五阶 80%。
- 投掷武器先执行现有随机等级逻辑，再保证拥有一个随机正面附魔。
- 两只秘库铁卫自身的装备掉落维持不变。
- 不额外散落近战武器或护甲；除投掷武器外，高阶装备仅来自秘库铁卫。

所有本局生成的可携带战利品带有持久化的局次标记。带标记物品不会与入场前的
同类堆叠物合并。成功撤离后清除标记；失败时删除全部带当前局次标记的物品，
包括背包、专用容器和已装备位置中的物品。

## 钥匙与撤离

- 从本局普通怪物中随机选择一只作为“钥匙携带者”，必定掉落一把本层水晶钥匙。
- 第二把水晶钥匙放入一个金箱。
- 金箱使用原有 `LOCKED_CHEST` 机制，必须消耗本层金钥匙开启。
- 一把本层金钥匙随机放置在普通可通行格。
- 撤离房间不产生普通上下楼 transition。英雄站在撤离点时可选择使用水晶钥匙。
- 没有水晶钥匙时只显示缺少钥匙提示，不允许离开。
- 一把水晶钥匙时正常撤离；两把水晶钥匙时额外获得 2000 金币。
- 结算时清理本层所有水晶钥匙和金钥匙，钥匙不能被带出或用于下一局。

## 入场、存档与返回

- `SurfaceShopkeeper` 菜单增加“搜打撤行动（1000金币）”。
- 选项仅在 0 层通过店主交互可用；选择后显示规则和风险确认。
- 金币不足时禁用确认；确认后扣除 1000 金币并记录原深度、分支和英雄位置。
- 每次入场都强制创建新的 `ExtractionRaidLevel`，不复用上一局第 31 层文件。
- 中途保存退出不判失败；读档继续同一随机种子、同一战利品和局次状态。
- 成功、死亡或主动放弃后加载原 0 层，并把英雄放回交谈前的位置，因此仍在店主身边。

## 成功与失败结算

用英雄身上的持久化局次 Buff 保存当前局次 ID、返回位置和活动状态。

成功：

1. 校验水晶钥匙数量。
2. 根据钥匙数量发放 0 或 2000 金币。
3. 清除所有本局战利品标记，使其成为普通永久物品。
4. 清理钥匙、负重和局次 Buff。
5. 返回 0 层店主身边。

失败：

1. 死亡时在普通复活/游戏结束逻辑之前拦截，不消耗十字架，不删除主存档。
2. 主动点击局次 Buff 的“放弃行动”并二次确认也会失败。
3. 删除当前局次的全部战利品。
4. 从非贵重消耗品中随机选择 1–2 个不同背包格，每格损失一件。
5. 候选仅包含普通药剂、卷轴、符石、种子和食物；排除力量/精通/升级/嬗变/
   附魔类物品、藏品、钥匙、唯一物品、背包、水袋和装备。
6. 英雄生命恢复到 `max(1, HT/4)`，清除致命持续伤害，然后返回店主身边。

若没有合格的普通消耗品，只失去本局战利品。

## 负重 Buff

负重 Buff 在英雄进入搜打撤楼层时强制附加，在成功撤离、死亡失败或主动放弃
离开楼层时强制移除，不会在 0 层或主地牢中生效。计数规则：

- 按占用的背包格计数，堆叠数量不影响重量。
- 递归统计背包和专用容器中的物品格。
- 不统计已装备物品、所有 `Bag` 容器本身和 `Waterskin`。

若背包格数为 `n`，装备加速保留比例为：

`retention(n) = (2/3)^n`

对极速戒指、迅捷和涌流分别应用：

`effectiveMultiplier = 1 + (originalMultiplier - 1) × retention(n)`

倍率低于或等于 1 时保持原值，因此负重不会把装备加速变成额外减速，也不会消除
护甲力量不足等原有惩罚。`Char.speed()` 中先计算极速药剂、激素涌动等消耗品效果，
负重只改写随后加入的戒指/附魔倍率，所以这些消耗品效果不受影响。

Buff 根据保留比例切换三级图标和说明：

- 轻载：保留至少 50% 装备加速。
- 中载：保留 20%–50% 装备加速。
- 重载：保留少于 20% 装备加速。

- 藏品测试验证价格边界、品质倍率、镇馆溢价和解析期望 5001.06075。

- 店主测试验证只有交互菜单能触发入口、金币不足时不能入场、返回位置正确。
