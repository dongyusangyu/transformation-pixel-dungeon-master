# 中式宗门大殿室内环境图集设计规格

## 1. 目标

为现有 16×16 像素地图系统设计一套完整的中式室内环境图集。主题采用已确认的 B1 方案：仍在使用、经过维护但可见年代感的宗门议事大殿。

最终图集需要同时满足：

- 一眼可辨的中式宗门大殿气质，而非日式和风室内。
- 与项目现有像素密度、光照方向、描边强度和地形语义兼容。
- 完整覆盖 `DungeonTileSheet` 的 256 个槽位，不改变现有槽位编号和拼接算法。
- 在 1 倍显示下仍能辨认门、锁、楼梯、井、书架、雕像、区域装饰等关键功能。
- 图集中不出现汉字、可读文字、伪汉字或类似文字的装饰笔画。

本阶段只设计并绘制环境素材，不接入新区域枚举、楼层代码或资源选择逻辑。

## 2. 参考素材

绘制时使用以下项目内素材作为结构或风格参考，所有路径均相对于仓库根目录：

- `core/src/main/assets/environment/tiles_halls.png`
  - 参考暗木、重阴影、危险区域的对比度和像素簇大小。
- `core/src/main/assets/environment/tiles_city.png`
  - 参考精细石材、文明建筑和少量暖色点缀。
- `core/src/main/assets/environment/tiles_prison.png`
  - 参考墙体、门体、锁门及上下层门框的槽位结构。
- `core/src/main/assets/environment/tiles_sewers.png`
  - 参考标准楼梯轮廓、水体 16 向过渡掩模和边缘拼接关系。
- `core/src/main/assets/environment/tiles_surface_lush.png`
  - 参考完整自定义图集、物件本体与 overhang 的分层对齐方式。
- `core/src/main/assets/environment/water0.png`
  - 参考独立水面纹理尺寸、透明度和动画读取方式。
- `tools/generate_lush_surface_tileset.py`
  - 参考可重复生成、按槽位绘制、保留模板掩模和输出 RGBA PNG 的实现方式。
- `core/src/main/java/com/shatteredpixel/shatteredpixeldungeon/tiles/DungeonTileSheet.java`
  - 作为图集索引、拼接位掩码和地形语义的唯一权威来源。

参考素材只提供结构、掩模和项目风格基准，不直接拼贴带有原区域地板背景的物件。

## 3. 视觉方向

### 3.1 场所与状态

场景是一座仍有人使用的宗门议事大殿。年代感表现为：

- 朱漆颜色变深，边缘有轻微磨损，但不大面积剥落。
- 灰砖存在少量细裂纹、色差与踩踏亮边，但结构完整。
- 暗木地板有局部磨亮和接缝，不出现腐烂或废墟感。
- 门、灯具、鼓架、铜鼎和陈设保持完整，体现持续维护。

### 3.2 中式识别元素

- 深朱漆立柱、双扇实木门、铜门钉和横向木梁。
- 灰砖墙基、深色木构、礼制化的对称构图。
- 空白黑漆匾面，只作为材质块面，不绘制任何文字或笔画。
- 屏风、地毯、门板使用回纹、云气、山形等抽象几何纹样。
- 武器架、卷轴柜、石狮、堂鼓、铜鼎、供案等室内陈设。

### 3.3 明确排除

- 不使用障子门、浅色纸格、榻榻米、鸟居、日本纸灯笼或大面积浅木色。
- 不依赖书法、牌匾文字、卷轴文字或伪文字表达主题。
- 不使用平滑渐变、半透明抗锯齿或非整数缩放产生的软边。
- 不把对象连同原参考图的地板背景一起复制到新图集。

## 4. 色板与光照

主色板如下，允许在相邻亮度上增加少量派生色，但应维持有限色板：

| 用途 | 颜色 |
| --- | --- |
| 炭黑轮廓 | `#1B1B19` |
| 深灰砖 | `#57574F` |
| 亮灰砖 | `#817B69` |
| 深木 | `#3A251D` |
| 暖木 | `#68402B` |
| 暗朱红 | `#67201D` |
| 朱红高光 | `#923126` |
| 暗铜 | `#695027` |
| 铜色 | `#B1843D` |
| 铜高光 | `#D1B35C` |
| 深玉色 | `#315D59` |
| 玉色高光 | `#668D79` |
| 灯火色 | `#D99A3F` |

统一采用左上方光源。红色只用于门、柱和少量地毯；铜色只作为门钉、锁具、鼎和器物高光；玉色只用于特殊门和矿物兼容槽，避免形成单一红色或金色画面。

## 5. 图集结构

### 5.1 输出

- `core/src/main/assets/environment/tiles_chinese_hall.png`
  - 256×256 RGBA。
  - 16 列 × 16 行，每格 16×16 像素。
- `core/src/main/assets/environment/water_chinese_hall.png`
  - 32×32 RGBA。
  - 蓝黑色室内映水纹理，与第三行水体过渡颜色一致。

所有图像使用最近邻像素工作流，不做抗锯齿。

### 5.2 槽位范围

| 索引范围 | 语义 | 设计要求 |
| --- | --- | --- |
| 0–23 | 基础地面和入口物件 | 灰砖、红毯、暗木台面、楼梯、井、供案 |
| 24–31 | 深渊及其上缘拼接 | 深暗空间，分别适配灰砖、木地板、墙和水 |
| 32–47 | 水体及 15 种地面过渡 | 保留 `tiles_sewers.png` 的方向位掩码和轮廓 |
| 48–63 | 平视墙、门、书架和出口 | 中式墙基、门扇、锁具和卷轴柜 |
| 64–79 | 平视其他物件 | 药鼎、障碍、屏风、碎片、雕像、鼓、鼎 |
| 80–111 | 抬高墙体下层 | 四种开边组合，普通、装饰、门后、书架墙均完整 |
| 112–119 | 抬高门体下层 | 关闭、打开、上锁、玉封和横向门底 |
| 120–143 | 抬高其他物件下层 | 对应 64–79 的主体层和矿物兼容槽 |
| 144–191 | 内墙上层 | 16 向普通墙、装饰墙和木制书架墙 |
| 192–223 | 墙体及横向门 overhang | 保持四向组合、门楣和锁门门楣语义 |
| 224–231 | 门和出口上下层补片 | 纵向门楣、横向门、锁门、玉封门和出口 underhang |
| 232–255 | 其他物件 overhang/underhang | 与主体连接的器物上部、屏风上部和碎片下部 |

任何未被当前主题重点使用的槽位也必须有结构正确的兼容图形，不得留作随意透明占位。

## 6. 地形和物件定义

### 6.1 地面

- `FLOOR`：深灰方砖，边缘有低对比度磨损和少量暖灰颗粒。
- `FLOOR_DECO`：暗红礼道或地毯，使用铜色铆钉或抽象几何边饰。
- `GRASS`：室内可破坏的矮屏风、竹帘或陈设占位的地面表现，不绘制自然草。
- `EMBERS`：熄灭或低燃的炭盆余烬，底色仍是灰砖。
- `FLOOR_SP`：深棕横向木板，用于主座高台或内室。
- 各 ALT 槽只改变磨损、裂纹、木结或纹样分布，不改变材质身份。

楼梯沿用 `tiles_sewers.png` 的项目标准轮廓，只进行材质和背景重配色。入口与出口必须在 1 倍显示下具有相反且明确的高低方向。

### 6.2 水与深渊

水体表现为蓝黑色室内映水池：

- 主水纹使用深玉蓝、灰蓝高光和稀疏水平反光。
- 32–47 保留原有 `+1 上、+2 右、+4 下、+8 左` 的过渡语义。
- 过渡轮廓以内必须是水纹，轮廓以外必须是当前灰砖地面，不得出现内外同材质。
- 第三行透明掩模和边缘位置以 `tiles_sewers.png` 为模板，颜色与 `water_chinese_hall.png` 匹配。

深渊使用炭黑至冷灰的硬边像素簇，顶部拼接分别适配灰砖、木地板、墙体和水面。

### 6.3 墙、书架和门

- 普通墙：灰砖墙基、深木横梁和暗朱立柱。
- 装饰墙：增加低对比度中式几何雕板，不增加文字。
- 书架：武器架与卷轴柜组合；卷轴标签为空白色块，不出现笔画。
- 普通门：重型暗朱双扇门、深木门框和稀疏铜门钉。
- 打开门：门叶向两侧收拢，中心通道清晰。
- 上锁门：门体仍完整可见，增加横向铜闩和足够大的锁具。
- 特殊门：玉绿色封印板与铜机械结构，不使用文字或符号。

平视、抬高、横向和纵向门体必须共享相同材质语言，并分别适配对应槽位的绘制方向。

### 6.4 功能物件

| 地形语义 | 中式室内表现 |
| --- | --- |
| `ALCHEMY` | 青铜药鼎或炼药锅 |
| `BARRICADE` | 堆叠座椅、屏风和木料 |
| `HIGH_GRASS` | 可破坏的高屏风或成束竹帘 |
| `FURROWED_GRASS` | 破碎木片、竹片和布片 |
| `STATUE` | 灰石镇守狮，背景为灰砖 |
| `STATUE_SP` | 同一石狮，背景为暗木高台 |
| `REGION_DECO` | 大型暗朱堂鼓 |
| `REGION_DECO_ALT` | 青铜鼎式香炉 |
| `MINE_CRYSTAL` | 玉石簇，用于兼容相关地形 |
| `MINE_BOULDER` | 坍落砖石，用于兼容相关地形 |
| `WELL` | 室内砌石井或下沉式水缸 |
| `EMPTY_WELL` | 干井或空水缸 |
| `PEDESTAL` | 低矮供案或礼器台 |

`REGION_DECO` 的主体层绘制鼓身下部和支架落地点，overhang 绘制鼓身上部及支架顶部；`REGION_DECO_ALT` 的主体层绘制鼎腹与足，overhang 绘制鼎耳和鼎盖。连接处宽度、中心轴和颜色必须逐像素一致，不允许悬浮或错位。

所有带地板的物件槽必须先绘制对应的新区域地面，再绘制对象。灰砖版本和木地板版本不得混用背景。

## 7. 生成实现

新增独立生成器 `tools/generate_chinese_hall_tileset.py`，不继续扩展地表图集生成器。生成器采用：

- 固定常量描述画布、格子尺寸、索引和色板。
- 固定随机种子生成可重复的砖缝、磨损和木结。
- 独立函数绘制地面、墙体、门、物件、水纹和 overhang。
- 结构模板只用于提取轮廓或透明掩模；颜色和对象背景由新主题重新绘制。
- 每次运行直接覆盖两张成品 PNG，不在资源目录保留预览或中间图。

不调用文字绘制 API，不加载字体，不使用生成式图像缩放替代逐像素绘制。

## 8. 验收标准

### 8.1 自动检查

- 图集尺寸、模式、16×16 网格和水纹尺寸正确。
- 相同输入连续生成两次得到完全相同的像素。
- 水体 16 向过渡掩模与参考结构一致，且水侧、地面侧颜色身份正确。
- 普通地面、木地板、墙体、门和关键物件槽非空且具有足够区分度。
- 门体与门楣、墙体与 overhang、鼓和鼎的主体与 overhang 连接像素对齐。
- 生成器源码不包含 `ImageFont`、`draw.text` 或其他文字绘制调用。
- 成品之外不新增预览或中间 PNG。

### 8.2 视觉检查

- 以最近邻方式查看 1 倍和 4 倍图集。
- 平铺至少 5×5 的普通砖、红毯、木地板和水纹，检查横纵拼接缝。
- 组合展示直墙、转角、内墙、四类门和锁门，检查方向与遮挡。
- 组合主体层和 overhang，检查堂鼓、铜鼎、石狮、屏风和药鼎无悬浮。
- 构建一间小型议事厅测试图，确认整体读作中式宗门大殿，不读作日式房间。
- 检查画面中不存在汉字、伪汉字、书法线条或可误读为文字的装饰。

临时检查图统一写入系统临时目录或 Codex 可视化目录，检查完成后删除，不进入仓库。
