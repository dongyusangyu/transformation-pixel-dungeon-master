# 地牢博士问答 NPC 设计

## 目标

在第 0 层地表城镇加入一名“地牢博士”。该 NPC 使用原版老杖匠 `WandmakerSprite`，固定站在北侧空房间内，为玩家提供连续四选一问答游戏。

NPC、题库模型、连续答题流程和全局统计主体已经完成。正式题库随后按照
`2026-07-29-dungeon-doctor-question-bank-design.md` 接入 200 道题，并将可见题目
资源与 Java 答案注册表分离。

## NPC 与生成位置

- 新建独立 NPC `DungeonDoctor`，不复用原版 `Wandmaker` 的任务逻辑。
- 使用 `WandmakerSprite`。
- 具有 `IMMOVABLE`，无限闪避，不接受伤害和 Buff。
- 第 0 层固定生成一个实例，位置为北侧房屋内部 `(22, 4)`。
- 地表层恢复或重复创建时不得生成重复实例。
- 中文名称为“地牢博士”，提供中英文名称和描述文本。

## 题目模型与题库

每道 `QuizQuestion` 包含：

- 稳定题目 ID。
- 题干。
- 恰好四个非空选项。
- 正确选项索引。
- 可选的答案说明；主体阶段允许为空。

选项按 Unicode 码点计数，每项最多 18 个字符。构造非法题目时抛出 `IllegalArgumentException`，避免 PDF 题库接入后产生无法显示的按钮。

`DungeonDoctorQuiz` 负责提供题库。生产题库由无答案文本资源和 Java 答案注册表
合并得到；加载或校验失败时回退为空题库，交互显示“题库尚未载入”，且不污染统计。

## 连续答题流程

与地牢博士交互打开主菜单：

1. 开始答题。
2. 查看统计。
3. 离开。

开始答题后创建一次临时 `QuizSession`，并由 `QuizRun` 状态控制器驱动窗口：

- 将当前题库随机打乱。
- 同一轮内每题最多出现一次。
- 玩家选择四个选项之一后立即记录一次答题。
- 同一道已展示题目最多记录一次；非法选项或重复提交不会写入统计。
- 结果窗口显示回答正确或错误、正确答案和可选说明。
- 若仍有题目，提供“下一题”和“结束”；题库耗尽后只提供“完成”。
- 会话只存在于窗口内，不写入游戏存档；重新与 NPC 交互会开始新一轮。

## 全局统计

统计存入 `SPDSettings`，因此跨角色、跨游戏存档共享：

- `quiz_answers_total`：累计作答数。
- `quiz_answers_correct`：累计正确数。

提供读取、记录和重置统计的 API。写入时保证非负、正确数不超过总数，并对整数上限做饱和处理。正确率实时由 `correct / total * 100` 计算；总数为零时显示 `0.0%`。

查看统计窗口显示累计答题总数、累计正确数和一位小数正确率。

## 本地化与测试

中英文消息覆盖 NPC 名称、描述、菜单、空题库、题干结果和统计窗口。

自动测试覆盖：

- 题目必须有四个短选项和合法正确索引。
- 连续会话随机顺序中不重复并正确结束。
- 答题状态流覆盖正确/错误、单题只记录一次、继续、主动结束和题库耗尽。
- `SPDSettings` 统计累计、正确率、重置和边界修正。
- NPC 使用老杖匠贴图且不可移动、不可伤害。
- 第 0 层只生成一个地牢博士并位于北侧房间。
- 生产题库资源与答案注册表一一对应，且资源文件不包含答案字段。
