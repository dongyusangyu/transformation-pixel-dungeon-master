# 地表店主设计规格

## 目标

在 `SurfaceTownLevel`（第 0 层）加入临时名为“店主”的特殊商人。店主使用原版商店老板贴图，固定生成在与“东隅桑榆”不同的房间。该房间作为地表商店，货架物品按第 20 层价格出售；店主还提供按名称查询并按第 25 层价格购买指定消耗品的功能。

## 房间与初始货架

- 使用地表城镇东北侧房屋并适当扩大，确保它与东隅桑榆所在的西南房屋物理分离。
- 店主生成在房间内部，使用 `ShopkeeperSprite`，保持普通商店老板不可移动等行为。
- 可购买物品以 `Heap.Type.FOR_SALE` 沿房间内侧边缘摆放。
- 每个货堆保存独立的“售价层数 20”，交易窗口和地面提示均读取该值，不能依赖当前 `Dungeon.depth`。
- 初始装备按恶魔层概率生成，即使用第 4 组楼层生成概率：20% 四阶、80% 五阶。
- 初始货架购买不计入查询购买限额。

## 店主交互

交互菜单包含：

1. 出售道具：复用普通商店老板的玩家出售功能与回购流程。
2. 查询购买：打开文本输入框。
3. 交谈：显示店主对话。
4. 回购项：若存在，沿用普通商店老板的回购入口。

查询输入兼容调试卷轴风格的尾随数量，例如：

- `治疗药剂`
- `治疗药剂 x3`

未写数量时默认为 1。只解析末尾、由空白分隔的 `xN`，避免破坏物品名称。

## 查询目录与排除规则

允许查询：

- 普通卷轴、密卷
- 普通药剂、对应的异变药剂
- 合剂、秘药
- 符石
- 种子

同时满足以下条件才可出售：

- 能按当前语言下的完整物品名称精确匹配（忽略首尾空白和英文大小写）。
- 物品 `value()` 大于 0。
- 不属于明确禁止的升级卷轴、力量药剂家族。

禁止：

- 升级卷轴、力量药剂。
- 它们的直接异变版本、由它们制作的种子、符石、密卷、合剂或秘药等衍生物。
- 无价格物品。
- 不在上述允许类别中的装备、神器、钥匙、剧情物品等。

## 定价、确认与限购

- 查询单价等同于该物品在第 25 层商店中的售价。
- 输入有效后显示确认窗口，列出物品、数量、单价、总价和该类物品剩余限额。
- 每个具体物品类累计最多通过查询购买 5 个；计数保存在该店主实例中并随存档持久化。
- 例如治疗药剂已购买 3 个，则最多再买 2 个；输入 `x3` 时整笔交易拒绝，不做部分成交。
- 金币不足、数量非正数、名称不匹配、超限或禁售时不扣款、不增加计数。
- 成交后优先放入背包；背包无法容纳时掉落到玩家脚下。
- 同一物品可以分多次查询购买，直至累计达到 5。

## 兼容性

- 原有普通商店继续使用当前楼层定价。
- 自定义售价层只作用于显式设置过的货堆，并随 `Heap` 存档。
- 地表关卡重复创建/恢复时只保留一个店主和一个东隅桑榆。
