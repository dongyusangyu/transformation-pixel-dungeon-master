# 死尸设计规格

## 目标

在高塔普通怪物包 `actors.mobs.tmobs` 中新增“死尸”（`Corpse`）。死尸是一个只能被治疗效果伤害的近战亡灵：所有常规伤害均无效，任何正数治疗都会转化为等量、无视护甲的伤害。死尸只有 1 点生命，因此第一次有效治疗必定将其击杀。

同时统一现有高塔普通生物的经验上限：`Bestiary.TOWER_MOBS` 中的迷彩豺狼、腐蚀蝇群和死尸均使用 `maxLvl = 30`。此调整不包含高塔 Boss。

## 数值

| 数值 | 设定 |
|---|---:|
| HP / HT | 1 |
| 伤害 | 10–40，平均 25 |
| 命中 | 40 |
| 闪避 | 20 |
| 护甲 | 0 |
| 移速 | 1，保留默认值 |
| 攻击间隔 | 1，保留默认值 |
| 经验 | 13 |
| 经验上限 | 30 |
| 额外掉落 | 无 |

死尸添加 `Char.Property.UNDEAD` 属性，但亡灵克制、武器攻击、法术和持续伤害仍会被专属受伤规则拦截。

## 治疗反转

采用怪物局部实现，不修改全局治疗系统。

- 覆写两个 `heal()` 重载。`heal(h)` 委托给 `heal(h, true)`。
- 当 `h > 0` 且死尸存活时，将完整的治疗数值转化为无视护甲、不可规避的伤害；不先按 `HT - HP` 截断，因此即使死尸当前处于满血也会受伤。
- 治疗不会真正增加 HP，`heal()` 返回 0，避免调用方把这次行为误认为成功恢复。
- `h <= 0`、死尸已死亡时不触发伤害。
- 覆写 `damage()` 并忽略所有外部伤害，包括物理、魔法、元素、腐蚀、中毒和其他持续伤害。
- 治疗伤害必须绕过死尸自身的 `damage()` 覆写，直接进入父类伤害与死亡流程，确保死亡动画、图鉴计数、经验结算和关卡移除逻辑正常执行。
- 使用专属治疗伤害来源标记，避免把死亡错误归因于普通物理或法术来源。

## 行为与生成

死尸复用普通近战 `Mob` 的追踪和攻击状态机，不增加远程、召唤或控制能力。

死尸只在 `TowerLevel` 对应的负数高塔楼层生成，不加入正常 1–25 层区域怪物池。负层生成概率调整为：

| 结果 | 概率 |
|---|---:|
| 迷彩豺狼 | 20% |
| 腐蚀蝇群 | 20% |
| 死尸 | 20% |
| 原高塔内容深度怪物池 | 40% |

死尸加入 `Bestiary.TOWER_MOBS` 的末尾，并由 `TowerMobPlacer` 从图鉴注册表自动读取。

## 相似对象

- 数值和近战状态机：高塔基准普通怪物、`Gnoll`。
- 亡灵属性：`Skeleton`、`Ghoul`。
- 治疗入口：`Char.heal(int)` 与 `Char.heal(int, boolean)`。
- 美术轮廓和动作：`core/src/main/assets/sprites/warrior.png` 的布甲层、`HeroSprite.updateHeroFrames()`。

## 精灵与动画

创建独立资源 `sprites/corpse.png`，不得在运行时对英雄资源做滤镜或动态换色。

- 从 `warrior.png` 的布甲层提取前 16 个 12×15 帧，保持原有身体比例、脚底基线、动作姿态和朝向。
- 帧 0–1：待机。
- 帧 2–7：六相行走。
- 帧 8–12：五阶段死亡。
- 帧 13–15：三阶段攻击。
- 精灵表尺寸为 192×15，单帧 12×15，不超过 16×16。
- 使用 A“腐绿尸斑”方向：灰绿皮肤、褐灰布甲、暗紫伤痕。
- 在不破坏原动作轮廓的前提下补充凹陷眼窝、腐败斑点和少量破损衣角；各帧的破损位置随身体运动保持一致。
- PNG RGBA、透明背景、硬边、无抗锯齿、无半透明像素，建议不超过 12 个可见颜色。

`CorpseSprite` 复用英雄布甲的动作节奏和帧序列：

- 待机：帧 0、1 的低速循环。
- 行走：帧 2–7 的快速循环。
- 攻击：帧 13–15，结束后回到待机。
- 死亡：帧 8–12，非循环播放。

## 文案

中文名称为“死尸”。描述需要明确传达：

> 这具腐败的躯体对刀剑与法术毫无反应，维系它的似乎正是死亡本身。任何试图修复血肉的治疗力量，反而会让它迅速崩解。

发现提示说明其仅出现在高塔负数楼层，但不直接泄露精确生成概率。

## 测试与验收

### 行为测试

- HP/HT 为 1，伤害上下界为 10 和 40，命中 40、闪避 20、护甲恒为 0。
- 默认移速和攻击间隔保持 1。
- 正常正伤害、0 伤害和持续伤害调用均不减少 HP。
- `heal(1)` 在满血时仍会击杀死尸并返回 0。
- `heal(0)` 和负数治疗不产生伤害。
- `heal(h, false)` 仍执行治疗反转。
- 迷彩豺狼、腐蚀蝇群和死尸的 `maxLvl` 均为 30。

### 接入测试

- 正常区域怪物池不包含死尸。
- 高塔负层纯选择规则按 20% / 20% / 20% / 40% 边界返回正确类型。
- `Bestiary.TOWER_MOBS` 末尾包含死尸，`TowerMobPlacer` 与图鉴注册表一致。
- `Assets.Sprites.CORPSE`、中英文文案和 `CorpseSprite` 引用独立资源。

### 素材测试

- `corpse.png` 为 192×15、16 帧、每帧 12×15。
- 16 帧全部非空，透明像素 RGB 清零，没有半透明像素。
- 可见颜色不超过 12。
- 每个非透明源轮廓像素在对应死尸帧中仍保持非透明，额外腐败细节不得造成明显动作逻辑错误。
